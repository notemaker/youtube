## 第一版介面與資料流程已完成

- [x] 建立收藏總覽介面：提供統計摘要、搜尋、篩選、排序與卡片式收藏清單，卡片呈現縮圖、關鍵資訊及可直接開啟的來源連結。
  - 首頁在桌機、筆電、平板與手機寬度下都能操作。
  - 搜尋可比對標題、來源、分類、標籤與備註。
  - 篩選包含影音類型、分類、標籤、觀看狀態與評分，並提供排序。
  - 無結果、載入中與空白資料時顯示清楚狀態。

- [x] 建立影音新增、檢視、編輯與刪除流程。
  - 表單至少包含標題、類型、來源連結、縮圖、分類、標籤、狀態、評分與備註。
  - 標題、來源連結、類型與狀態為必要驗證欄位。
  - 成功與錯誤都提供可理解的繁體中文回饋；刪除需有確認步驟。
  - 詳情面板集中呈現收藏資訊與相關操作，手機版可全螢幕使用。

- [x] 建立 Google Apps Script Web App 設定與資料來源切換。
  - 設定頁可輸入 API URL、切換示範資料／Google Sheet 模式並顯示連線狀態。
  - 對應 `list`、`meta`、`create`、`update`、`delete` 動作與 `{ok,data,error,meta}` 回應格式。
  - 規格中定義的 `Media` 與 `Lists` 欄位可直接映射到 Google 試算表。
  - 顯示部署步驟、權限注意事項與前端串接設定。

- [x] 建立響應式視覺系統與互動回饋。
  - 採「編輯室索引卡／夜間放映」風格，以墨綠、米白、播放橘與鼠尾草色建立層次。
  - 桌機以側欄加卡片網格呈現；平板彈性雙欄；手機單欄並提供固定新增操作。
  - 面板、toast、狀態與焦點樣式需清楚，不依賴 hover 才能完成操作。
